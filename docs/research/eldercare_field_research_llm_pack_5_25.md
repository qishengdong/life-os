# KEY 养老知识库 · LLM 田野调研 Prompt Pack · 5/25/2026

**目的**: 给创始人 5/25 后真用的完整 prompt 库. 你复制粘贴到各 LLM, 真数据回来后我帮你结构化进 KEY 知识库.
**总工作量预估**: 创始人 + 1 助手 · 4-8 周可完成 Layer 1+3+4 (medical/legal/relational), Layer 2+5 (居住+城市资源) 需 8-12 周真田野.
**LLM 配置建议**: 同时开 Claude Pro / Kimi / 豆包 / 文心 / Perplexity · 5 平台并行 cross-check 真信息.

## 一. 真使用指南 · 哪个 LLM 干哪个

| LLM | 强在哪 | 适合做 |
|---|---|---|
| **Claude (claude.ai)** | 长文档分析 + 跨文献综合 + 真克制 | Module A (医学综合) / D (心理深度) / 总结整理 |
| **Kimi (kimi.moonshot.cn)** | 长 context + 中文 web search + 联网 | Module E (城市真资源) / B (真供应商) · **最重要** |
| **豆包 (doubao.com)** | 中文本地知识 + 字节系真贴近 | Module E 中国特色 / B 中国家政市场 / F 真用户经验 |
| **文心一言 (yiyan.baidu.com)** | 中文医学/法律 + 政府数据 | Module A 中国医学共识 / C 中国法规 |
| **DeepSeek (deepseek.com)** | 中文逻辑 + 便宜 + 高量 | 批量处理 / 多城市 parallel |
| **Perplexity** | 带 source 真搜索 + 英文医学 SCI | Module A 国际医学交叉验证 |
| **ChatGPT (chat.openai.com)** | 广泛知识 + 英文 | 国际养老最佳实践对照 |

**真协作模式**: 每个 prompt 至少**2 个 LLM cross-check**. 一致 → 高 confidence. 冲突 → 标红 → 你/真专家定夺.

## 二. 输出真统一格式 (所有 prompt 要求 LLM 用)

每个 prompt 末尾要加这段:

```
请用以下结构化 markdown 格式输出, 方便后续整理:

## [主题]
### 来源 (Source)
- 列举所有引用的真权威 source (优先 .gov / .edu / .org / 主流学术)
- 标注每条信息的具体 source

### 核心要点 (Key Facts)
- 用 bullet point, 每条 ≤ 80 字
- 数字必须准确 (有 source)

### 关键决策影响 (Decision Impact)
- 这些事实对子女做养老决定有什么真实影响?

### 不确定 / 需真验证 (Needs Verification)
- 哪些信息你不 100% 确定?
- 哪些需要本地真人去现场看?
- 哪些可能过时?

### 引用真原文 (Verbatim Quotes)
- 如有指南/共识原文, 引用 ≥ 2 句 verbatim
```

## A1 · 失智症 4 类真详细 (最重要)

**用哪个 LLM**: Claude (主) + 文心 (中文医学共识) + Perplexity (国际共识)

**真 Prompt**:
```
你是中国老年医学专家. 我在做一个帮助中国子女做父母养老决策的产品.
我需要关于失智症 (Dementia) 的真权威临床知识.

请按以下结构详细回答, 每条都要引用具体 source (中华医学会指南 / WHO / NIH /
JAMA / Lancet 等真权威):

1. **失智症 4 大类型真区别** (阿尔茨海默 / 血管性 / 路易体 / 额颞叶):
   - 真发病机制
   - 真早期症状 (子女最容易看到的 5 个信号)
   - 真平均进程时长 (从早期到中度到晚期, 每个阶段 N 年)
   - 真不同点 (家属容易混淆的)

2. **早期信号家属真该警觉的 8 个**:
   - 不是"老糊涂", 是真临床信号的 8 个具体表现
   - 每个信号真意味着什么 (失智症进程哪个阶段)

3. **进程预测真模型**:
   - 从早期到完全失能平均多少年? (中位数 + 区间)
   - 哪些因素加速? 哪些因素延缓?
   - 真临床量表 (MMSE / MoCA / CDR) 真分数对应什么阶段

4. **真不可逆 vs 真可逆**:
   - 哪些早期信号其实是其他可治疗病引起 (如 B12 缺乏 / 抑郁 / 甲状腺)?
   - 子女多久该带去神经科真评估?

5. **真治疗 + 真没用的**:
   - 中国市面 (国内) 哪些药真有效 (按 GRADE 证据等级)?
   - 哪些保健品是真智商税?
   - 非药物干预真有效的 3 件事

请用我上面给的"输出真统一格式" 结构化输出.
最后, 标注: 哪些是中国特有 (vs 国际), 哪些 source 来自中国指南.
```

**Cross-check 真问**: 同样问题问 Perplexity (要求引 SCI), 对比答案差异.

# 三. 真 Quality Control 协议

## QC 1 · Cross-check 真规则

每个 prompt 至少**2 个 LLM** 跑. 对比:
- **完全一致** → 高 confidence · 直接入库
- **大致一致, 细节差异** → 中 confidence · 标注差异 · 入库时 caveat
- **明显冲突** → 低 confidence · 标红 · 需真人验证

## QC 2 · 真 source 真验证

LLM 引用的 source 必须**抽样真验证**:
- 政府文件 (.gov.cn / .gov / .org) 真打开看
- 学术文献 真去 PubMed / CNKI 真查
- 新闻真打开看

## QC 3 · 真田野真核实 (Module E 必须)

Module E (城市资源) **绝对不能只信 LLM**. 必须:
- 北京真田野走 ≥ 10 家养老院 + 5 家医院老年科
- 上海真田野走 ≥ 10 家
- (其他城市可暂时只用 LLM, 等真用户在那城市时再田野)

## QC 4 · 真季度 update
