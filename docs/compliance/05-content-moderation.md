# 05 — 内容审核机制

> 备案表"安全措施"项对应内容. 重点说"我们怎么拦不该出现的内容".

## 1. 三层拦截架构

```
用户输入
   ↓
[Layer 1] 输入端关键词检测 (lib/safety/keywords.ts)
   ├── 命中 CRISIS → 不入 LLM, 返回热线
   ├── 命中 BLOCKLIST → 不入 LLM, 不存档, 中性拒绝
   ├── 命中 MEDICAL → 不入 LLM, 转介医生
   ├── 命中 LEGAL → 不入 LLM, 转介律师
   └── 命中 FINANCE → 不入 LLM, 转介财务顾问
   ↓ (没命中)
[Layer 2] LLM 调用 (含 system prompt 边界提示)
   ↓
[Layer 3] 输出端二次审查 (lib/safety/index.ts sanitizeOutput)
   ├── 命中 BLOCKLIST → 替换为中性回复
   └── 通过 → 追加 AI 生成标识 → 返回
```

## 2. 关键词库

### 2.1 CRISIS (生命安全)
- 直接信号: 自杀 / 自伤 / 想死 / 不想活 / 想消失 / ...
- 强度信号: 撑不下去 / 没意义活 / 反正没人需要 / ...
- 方法描述: 跳楼 / 跳河 / 上吊 / 割腕 / 吞药 / ...
- 时间紧迫: 今晚就 / 马上 / ...

命中后**统一响应** (硬编码, LLM 改不动):
```
我听见你说的了. 这话我得认真接住.
北京心理危机干预中心 24 小时 010-82951332
全国心理援助热线 400-161-9995
你身边有没有一个能让你说"我不太好"的人?
```

### 2.2 MEDICAL / LEGAL / FINANCE
- 明确转介专业人士
- 但允许继续讨论 "如何挂上号 / 如何跟家人开口 / 资源配置框架" 等元话题

### 2.3 BLOCKLIST
- 涉黄 / 涉暴 / 涉毒 / 极端组织
- 命中后中性拒绝, **不存档原始输入** (避免污染数据库)

### 2.4 政治敏感词
- 不在源代码硬编码 (维护成本 + 维度敏感)
- 通过外部关键词文件加载 (`data/political-keywords.txt`, gitignore)
- 文件来源: 省网信办参考库 + 行业公开整理
- 命中归为 BLOCKLIST 处理

## 3. System Prompt 边界 (Layer 2 内嵌)

所有 LLM 调用都附带"反鸡汤宪法"作为 system prompt, 包含:

```
【边界提示(强制)】
- 涉及医疗诊断 → 必须建议咨询医生
- 涉及法律纠纷 → 必须建议咨询律师
- 涉及具体投资 → 必须建议咨询专业财务顾问
- 涉及自伤 / 严重抑郁信号 → 必须提供专业心理援助资源
```

Pulse 处理器 prompt 同样硬编码 L3 危机协议 + 三类红线.

## 4. 输出标识 (合规要求)

按《互联网信息服务深度合成管理规定》第十六 / 十七条,
所有 AI 生成的长输出自动追加标识:

```
---
*以上内容由 AI 生成, 仅作为决策辅助参考, 不构成医疗、法律或财务建议.
重大决定请结合专业意见.*
```

实现见 `lib/safety/disclosure.ts`.

## 5. 测试验证

- 200 道分类测试题, 每次发版前跑 (见 04-safety-self-assessment.md §5)
- Real Grader v3 + 12 维评分, 价值观对齐 dim 必须 ≥ 4.5/5
- Adversarial swarm 测试 (人格 7 个 + 真实诱导话术), 防御率 ≥ 95%

实测数据 (2026-05-11):
- v1 第一次跑: 50% (3 个 P0 fail — L3 crisis / 医诊 / 婚姻误路由)
- 修后: 88-100% 防御
- Real Grader 4.97/5
