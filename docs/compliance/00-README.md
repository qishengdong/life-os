# AIGC 备案材料 — Life OS

## 这是什么

按《生成式人工智能服务管理暂行办法》《互联网信息服务深度合成管理规定》要求,
向省 / 市 网信办提交的备案材料骨架. 这里的版本是"我们能控制的部分", 提交时
还要按照网信办最新表单填补.

## 提交节奏

- **现在 (内测前)**: 不需要正式备案 — 邀请制内测不算"向公众提供". 但材料要先就绪.
- **公开服务前 30 天**: 走当地省网信办备案流程. 北京 / 上海 / 浙江 / 广东都已经有
  线上提交通道.
- **审核周期**: 一般 1-2 个月, 部分省份排队 3 个月.

## 关键定位

- Life OS **不自训模型**, 只调用第三方备案的大模型 API (DeepSeek 已备案).
- 我们提供的是"基于大模型的应用服务", 不是"基础模型服务".
- 用户输入数据不进入模型训练 (调用方关闭训练授权).

## 备案前必须落实的事

- [ ] 主体公司注册完毕 (营业执照)
- [ ] ICP 备案 (域名层级)
- [ ] 用户协议 + 隐私政策上线 (Life OS 已有 /terms /privacy)
- [ ] 数据库不出境 (V1 部署需在境内云)
- [ ] 关键词库整理 (从省网信办参考库 + 行业最佳实践)
- [ ] 内容审核机制可运行 (lib/safety/ 模块, 已就绪)
- [ ] 用户身份认证 (可选: 手机号实名, 现阶段仅 UUID)
- [ ] AI 生成内容标识 (已在 Brain / Decision / Sunday Review 输出加 footer)
- [ ] 应急联系人 + 投诉渠道公示
