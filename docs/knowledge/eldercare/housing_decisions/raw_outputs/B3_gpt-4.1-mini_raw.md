# 二、各类养老院详细解析

## 1. 普通养老院（自理为主）

- **入住条件**：身体基本健康，能自理生活，部分机构要求60岁以上，需体检合格。  
- **适合老人**：自理老人，偶尔需要生活辅助。  
- **常见坑**：护理人员比例低（1:20以上常见），医疗资源缺乏，突发疾病应急能力差，隐形收费（如床单费、活动费等）多。  

## 2. 失能照护院（生活照料）

- **入住条件**：需提供失能证明（如ADL评分），部分要求医保或社保缴纳证明。  
- **适合老人**：中度失能老人，日常生活需帮助。  
- **常见坑**：护理员资质不一，护理比例不足（理想1:5，实际常见1:10以上），护理员流动率高，服务质量不稳定。  

## 3. 失智专区（Memory Care）

- **入住条件**：需专业医生诊断失智症，部分机构要求家属陪护协议。  
- **适合老人**：认知障碍、阿尔茨海默病患者。  
- **常见坑**：专业护理人员缺乏，环境安全隐患（逃逸风险），认知康复效果难量化，费用高。  

## 4. 医养结合院

- **入住条件**：需医疗评估，慢病患者优先。  
- **适合老人**：慢性病多发、失能老人。  
- **常见坑**：医疗资源不均，医疗费用不透明，医保报销政策复杂，部分机构医疗资质存疑。  

## 5. CCRC（持续照护退休社区）

- **入住条件**：经济实力强，签订长期合同。  
- **适合老人**：计划长期居住，需求多样。  
- **常见坑**：高押金，合同复杂，转级机制不透明，服务质量参差。  

## 6. 高端疗养院 / 长者公馆

- **入住条件**：经济实力强，健康评估合格。  
- **适合老人**：高端自理及失能老人。  
- **常见坑**：价格虚高，服务与宣传不符，隐形收费，合同条款复杂。
