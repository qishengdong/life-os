## 老年人多重用药风险管理：子女必读指南

### 核心要点 (Key Facts)

#### 1. 子女最该警觉的 10 个老年用药危险信号

老年人生理功能衰退，药物代谢和排泄能力下降，对药物的敏感性增加，不良反应发生率更高且常表现不典型 [2]。以下是子女应高度警惕的危险信号及其可能原因：

*   **突然嗜睡/精神萎靡**:
    *   **可能药物**: 镇静安眠药（如苯二氮卓类：地西泮、艾司唑仑）、抗组胺药（如苯海拉明）、阿片类止痛药、某些抗抑郁药、肌肉松弛剂、降压药过量（导致低血压引起脑供血不足）[1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (苯二氮卓类、第一代抗组胺药被列为PIMs)；[4] 药品说明书。
*   **突然摔倒/步态不稳**:
    *   **可能药物**: 镇静安眠药、抗抑郁药（特别是三环类抗抑郁药）、抗精神病药、降压药（特别是利尿剂、α受体阻滞剂，引起体位性低血压）、降糖药（引起低血糖）、肌肉松弛剂 [1, 2]。
    *   **来源**: [1] Beers Criteria 2019 (多种药物与跌倒风险增加相关)；[2] 中国老年医学学会多重用药管理专家共识。
*   **突然意识模糊/谵妄 (Confusion)**:
    *   **可能药物**: 抗胆碱能药物（如苯海拉明、三环类抗抑郁药、奥昔布宁）、镇静安眠药、阿片类止痛药、皮质类固醇、某些抗生素（如氟喹诺酮类）、地高辛中毒、利尿剂引起电解质紊乱 [1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (抗胆碱能药物、苯二氮卓类被列为PIMs)；[4] 药品说明书。
*   **食欲不振/恶心呕吐**:
    *   **可能药物**: 地高辛、非甾体抗炎药 (NSAIDs)、二甲双胍、抗生素、阿片类止痛药、化疗药物 [4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
*   **异常出血/瘀斑**:
    *   **可能药物**: 抗凝药（如华法林、利伐沙班）、抗血小板药（如阿司匹林、氯吡格雷）、非甾体抗炎药 (NSAIDs) [1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (NSAIDs与出血风险)；[4] 药品说明书。
*   **心悸/心律不齐**:
    *   **可能药物**: 某些抗心律失常药（如胺碘酮、奎尼丁）、支气管扩张剂（如沙丁胺醇）、甲状腺激素过量、某些抗抑郁药、伪麻黄碱（感冒药成分）[1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (某些抗心律失常药在老年人中慎用)；[4] 药品说明书。
*   **排尿困难/尿潴留**:
    *   **可能药物**: 抗胆碱能药物（如奥昔布宁、托特罗定、三环类抗抑郁药）、某些抗组胺药、α受体激动剂（如伪麻黄碱）[1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (抗胆碱能药物被列为PIMs)；[4] 药品说明书。
*   **便秘加重**:
    *   **可能药物**: 阿片类止痛药、抗胆碱能药物、钙通道阻滞剂（如维拉帕米）、铁剂、某些抗抑郁药 [1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (阿片类药物、抗胆碱能药物)；[4] 药品说明书。
*   **水肿加重/体重异常增加**:
    *   **可能药物**: 非甾体抗炎药 (NSAIDs)、钙通道阻滞剂（如氨氯地平）、皮质类固醇、某些降糖药（如噻唑烷二酮类）[4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
*   **视力模糊/眼压升高**:
    *   **可能药物**: 抗胆碱能药物（如阿托品、某些感冒药）、皮质类固醇（长期使用可能导致青光眼）[1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (抗胆碱能药物)；[4] 药品说明书。

#### 2. 真高危药物互动 top 20

中国老年人常见多重用药，药物相互作用风险极高 [2]。以下列举常见且高危的药物组合及其后果：

1.  **华法林 + 非甾体抗炎药 (NSAIDs，如布洛芬、双氯芬酸)**
    *   **后果**: 严重出血风险（胃肠道出血、脑出血）显著增加 [1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (NSAIDs与抗凝药联用风险)；[4] 华法林说明书。
2.  **华法林/新型口服抗凝药 (NOACs，如利伐沙班、达比加群) + 阿司匹林/氯吡格雷**
    *   **后果**: 出血风险（特别是胃肠道出血）显著增加 [4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
3.  **ACEI/ARB类降压药 (如卡托普利、缬沙坦) + 螺内酯/依普利酮 (保钾利尿剂)**
    *   **后果**: 高钾血症，严重时可致心律失常甚至心脏骤停 [4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
4.  **二甲双胍 + 碘造影剂**
    *   **后果**: 增加乳酸性酸中毒风险，尤其在肾功能不全患者中 [4]。
    *   **来源**: [4] 二甲双胍说明书。
5.  **磺脲类降糖药 (如格列美脲、格列齐特) + β受体阻滞剂 (如美托洛尔)**
    *   **后果**: β受体阻滞剂可能掩盖低血糖症状（如心悸），并可能延缓低血糖恢复，增加严重低血糖风险 [4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
6.  **苯二氮卓类 (如地西泮、艾司唑仑) + 阿片类止痛药 (如曲马多、吗啡)**
    *   **后果**: 严重镇静、呼吸抑制、昏迷甚至死亡风险显著增加 [1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (苯二氮卓类与阿片类联用风险)；[4] 药品说明书。
7.  **地高辛 + 胺碘酮/维拉帕米/奎尼丁**
    *   **后果**: 增加地高辛血药浓度，导致地高辛中毒（恶心、呕吐、心律失常、黄视等）[4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
8.  **他汀类降脂药 (如辛伐他汀) + 大环内酯类抗生素 (如克拉霉素、红霉素)**
    *   **后果**: 增加他汀类药物引起的肌病和横纹肌溶解风险 [4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
9.  **选择性5-羟色胺再摄取抑制剂 (SSRIs，如氟西汀、舍曲林) + 非甾体抗炎药 (NSAIDs)**
    *   **后果**: 增加胃肠道出血风险 [4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
10. **钙通道阻滞剂 (如氨氯地平、维拉帕米) + β受体阻滞剂 (如美托洛尔)**
    *   **后果**: 增加心动过缓、房室传导阻滞和心力衰竭风险，特别是维拉帕米或地尔硫卓与β受体阻滞剂联用 [4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
11. **利尿剂 (如氢氯噻嗪、呋塞米) + 非甾体抗炎药 (NSAIDs)**
    *   **后果**: 降低利尿剂效果，增加肾功能损害风险 [4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
12. **抗胆碱能药物 (如苯海拉明、奥昔布宁) + 其他抗胆碱能药物 (如三环类抗抑郁药)**
    *   **后果**: 叠加抗胆碱能不良反应（口干、便秘、尿潴留、视力模糊、认知障碍、谵妄）风险显著增加 [1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (多种抗胆碱能药物被列为PIMs)；[4] 药品说明书。
13. **左旋多巴 + 维生素B6**
    *   **后果**: 维生素B6会加速左旋多巴在外周的代谢，降低其治疗帕金森病的疗效 [4]。
    *   **来源**: [4] 左旋多巴说明书。
14. **甲状腺激素 (如左甲状腺素) + 钙剂/铁剂**
    *   **后果**: 钙剂和铁剂会影响甲状腺激素的吸收，降低其疗效。应间隔至少4小时服用 [4]。
    *   **来源**: [4] 药品说明书。
15. **质子泵抑制剂 (PPIs，如奥美拉唑) + 氯吡格雷**
    *   **后果**: 某些PPIs（如奥美拉唑）可能通过抑制CYP2C19酶，降低氯吡格雷的抗血小板活性，增加心血管事件风险 [4, 5]。
    *   **来源**: [4] 药品说明书；[5] UpToDate。
16. **降糖药 (如胰岛素、磺脲类) + 酒精**
    *   **后果**: 增加低血糖风险，酒精还可能掩盖低血糖症状 [4]。
    *   **来源**: [4] 药品说明书。
17. **降压药 (如α受体阻滞剂、利尿剂) + 酒精**
    *   **后果**: 增加体位性低血压和跌倒风险 [4]。
    *   **来源**: [4] 药品说明书。
18. **抗精神病药 (如利培酮、奥氮平) + 降压药**
    *   **后果**: 增加体位性低血压和跌倒风险 [1, 4]。
    *   **来源**: [1] Beers Criteria 2019 (抗精神病药与跌倒风险)；[4] 药品说明书。
19. **地西泮/艾司唑仑 + 酒精**
    *   **后果**: 严重中枢神经系统抑制、呼吸抑制、昏迷 [4]。
    *   **来源**: [4] 药品说明书。
20. **西地那非 (伟哥) + 硝酸酯类药物 (如硝酸甘油)**
    *   **后果**: 严重低血压，可能危及生命 [4]。
    *   **来源**: [4] 药品说明书。

#### 3. 真子女应对操作

*   **帮助父母整理药物**:
    *   **周药盒**: 购买带日期和时间分隔的周药盒，将每天、每餐的药物提前分装好。这能有效避免漏服、重复服用或混淆药物 [2]。
    *   **不丢不重复**: 每次服药前，子女或照护者应核对药盒中的药物与医嘱是否一致。定期清理过期药物。
    *   **药物清单**: 制作一份详细的药物清单，包括药物名称、剂量、用法、适应症、开药医生和开药日期。
    *   **来源**: [2] 中国老年医学学会多重用药管理专家共识 (强调药物整理的重要性)。

*   **何时该真问医生重新评估 (Deprescribing)**:
    *   **出现新的症状或不良反应**: 任何上述危险信号出现时，都应及时就医，并告知医生所有正在服用的药物。
    *   **药物数量过多**: 当服药种类超过5种时，多重用药的风险显著增加，应考虑药物重评估 [2]。
    *   **治疗目标改变**: 随着年龄增长或疾病进展，治疗目标可能从治愈转向改善生活质量，某些预防性药物可能不再必要。
    *   **肾功能/肝功能下降**: 老年人肾功能和肝功能常有不同程度下降，需调整药物剂量或停用某些药物 [2]。
    *   **Beers Criteria中列出的不当用药**: 如果父母正在服用Beers Criteria中明确不建议老年人使用的药物，应与医生讨论替代方案 [1]。
    *   **来源**: [1] Beers Criteria 2019；[2] 中国老年医学学会多重用药管理专家共识 (强调Deprescribing的重要性)。

*   **真该备什么记录 (中国电子病历真碎，怎么自己整理)**:
    *   **纸质/电子版药物清单**: 包含所有处方药、非处方药、保健品、中草药的名称、剂量、用法、适应症、开药医生、开药日期。每次就诊时更新并携带。
    *   **过敏史**: 详细记录所有药物过敏史及过敏反应类型。
    *   **主要诊断和病史**: 记录所有慢性病诊断、手术史、住院史。
    *   **医生联系方式**: 记录主要专科医生的姓名和联系方式。
    *   **不良反应记录**: 详细记录服药后出现的任何不适，包括发生时间、症状、持续时间、怀疑的药物。
    *   **化验检查结果**: 定期整理血常规、肝肾功能、电解质、血糖、血脂等重要化验结果。
    *   **来源**: [2] 中国老年医学学会多重用药管理专家共识 (建议建立个人用药档案)。

#### 4. 真避坑 (中国特有)

*   **中老年人爱囤的保健品哪些跟处方药真冲突?**
    *   **银杏叶制剂**: 与抗凝药（华法林、阿司匹林）联用增加出血风险 [4, 5]。
    *   **人参/西洋参**: 可能影响血糖，与降糖药联用需监测血糖；可能影响抗凝药效果 [4, 5]。
    *   **鱼油 (高剂量)**: 与抗凝药联用可能增加出血风险 [5]。
    *   **圣约翰草**: 强效CYP450酶诱导剂，可降低多种药物（如华法林、地高辛、口服避孕药、抗抑郁药）的血药浓度，导致疗效下降 [4, 5]。
    *   **钙剂/铁剂**: 与甲状腺激素、某些抗生素（如四环素、氟喹诺酮类）联用会影响吸收，需间隔服用 [4]。
    *   **来源**: [4] 药品说明书；[5] UpToDate (保健品与药物相互作用章节)。
    *   **核心要点**: 任何保健品都应告知医生和药师，不可盲目服用，特别是与处方药同时使用。

*   **"大医院开的药一定对" 这个真假?**
    *   **真假**: **不完全是真**。大医院的医生专业水平高，但老年人常在多个科室就诊，各科医生可能不了解患者在其他科室开具的所有药物，导致重复用药或药物相互作用 [2, 3]。此外，老年人个体差异大，即使是“对”的药，剂量也可能需要个体化调整。
    *   **来源**: [2] 中国老年医学学会多重用药管理专家共识 (指出多科室就诊是多重用药风险来源)；[3] 中国药学会医院药学专业委员会老年用药安全管理专家共识。
    *   **核心要点**: 即使是大医院的处方，也需要子女积极参与管理，整合信息，并向医生提供完整的用药清单。

*   **跨医院开药互不知 → 怎么避免重复?**
    *   **统一用药清单**: 每次就诊时，主动向医生提供一份最新的、完整的用药清单（包括所有处方药、非处方药、保健品）。
    *   **固定就诊医院/医生**: 尽可能在同一家医院或由同一位全科医生/老年科医生进行主要管理，便于医生掌握患者的整体情况。
    *   **药师咨询**: 利用医院药房的药师资源，请药师审核药物清单，发现潜在的重复用药或相互作用 [2]。
    *   **电子健康档案**: 鼓励父母使用当地的电子健康档案系统（如有），并授权子女查看和管理。
    *   **来源**: [2] 中国老年医学学会多重用药管理专家共识 (建议药师参与多重用药管理)。
    *   **核心要点**: 子女是父母用药安全的“守门人”，主动沟通和信息整合是关键。

### 关键决策影响 (Decision Impact)

*   **子女应成为父母用药管理的积极参与者和协调者**，而非被动接受者。
*   **定期审查父母的用药清单**，并主动与医生和药师沟通，是预防药物不良事件的关键。
*   **对父母出现的任何异常症状保持高度警惕**，并将其与用药联系起来，及时寻求专业帮助。
*   **认识到多重用药的普遍性和高风险性**，不迷信“大医院开的药就一定对”，而是要主动整合信息，避免重复和冲突。
*   **在父母用药管理中，Deprescribing（合理减药）与合理用药同等重要**。

### 不确定 / 需真验证 (Needs Verification)

*   **中国65+老人平均每天吃5-7种药的具体数据来源**: 这是一个普遍的临床观察和共识，但精确到“5-7种”的全国性、最新、大规模流行病学调查数据可能需要进一步查证。目前共识多指出“多于5种药即为多重用药” [2]。
*   **中国特有的保健品与药物冲突的详细列表**: 尽管列举了一些常见保健品，但中国市场保健品种类繁多，成分复杂，其与处方药的相互作用研究可能不如西方国家充分，需要更详细的本地化研究数据支持。
*   **中国电子病历互联互通的实际情况**: 尽管国家在大力推行，但不同医院、不同区域之间的电子病历互联互通程度仍有差异，实际操作中可能仍存在信息壁垒，需要子女在当地实际验证。
*   **Beers Criteria的中国本土化适应性**: Beers Criteria是基于西方人群和药物制定的，虽然具有普适性，但中国老年人的疾病谱、用药习惯和可及药物可能存在差异，其在中国应用的具体细节和调整建议，需参考中国老年医学共识。
