- **GPT-4.1-Mini**: 认知严重下降、进食减少、体重持续下降、反复感染、意识模糊、活动能力极度减退，平均临终期 6 个月内。
- **Gemini-2.5-Flash**: 吞咽困难加重、进食量显著减少、反复感染（吸入性肺炎/尿路感染）、卧床不起、大小便失禁、意识水平进行性下降、最终呼吸衰竭或多器官功能衰竭。
- **GPT-4.1-Nano**: 认知严重下降、无法沟通、吞咽困难、感染频发。
- **一致性判定**: **极高**。三模型完全一致，核心信号为：吞咽困难 → 反复感染 → 意识下降 → 多器官衰竭。Gemini 提供了最详细的临床描述。
- **置信度**: 极高。

### 2. 心衰晚期临终轨迹

- **GPT-4.1-Mini**: 反复心衰加重、呼吸困难加剧、夜间阵发性呼吸困难、肢体水肿、肾功能下降。
- **Gemini-2.5-Flash**: 呼吸困难进行性加重（静息状态下明显）、水肿反复发作且对利尿剂反应不佳、反复心律失常、乏力虚弱、最终心源性休克或恶性心律失常。
- **GPT-4.1-Nano**: 持续低血压、严重水肿、运动能力丧失、多器官功能衰竭。
- **一致性判定**: **极高**。三模型完全一致，核心信号为：呼吸困难进行性加重 → 利尿剂无效 → 心律失常 → 多器官衰竭。Gemini 补充了"对利尿剂反应不佳"这一关键判断标准。
- **置信度**: 极高。

### 3. 癌症晚期临终轨迹

- **GPT-4.1-Mini**: 肿瘤负荷大、疼痛难控、体重快速下降、恶液质明显、意识障碍、器官功能衰竭。
- **Gemini-2.5-Flash**: 恶病质明显、疼痛控制困难（常规止痛药效果不佳）、反复感染/出血/梗阻、意识水平改变（嗜睡/谵妄/昏迷）、器官功能衰竭。
- **GPT-4.1-Nano**: 疼痛难以缓解、体重下降、虚弱明显。
- **一致性判定**: **极高**。三模型完全一致，核心信号为：恶病质 → 疼痛难控 → 意识改变 → 器官衰竭。Gemini 补充了"常规止痛药效果不佳"作为转安宁的具体判断标准。
- **置信度**: 极高。

### 4. DNR（放弃抢救）中国法律地位

- **GPT-4.1-Mini**: 法律允许患者或代理人签署 DNR 同意书，医疗机构必须尊重患者意愿，但具体执行因地制宜。
- **Gemini-2.5-Flash**: 中国法律目前**没有明确的 DNR 或生前预嘱专门立法**，但《民法典》保障公民自主决定医疗措施的权利。实践中通过"放弃抢救同意书"或"不予心肺复苏同意书"执行，法律效力存在不确定性。
- **GPT-4.1-Nano**: DNR 在中国法律地位**尚未明确**，但在试点中逐步被认可。
- **一致性判定**: **高**。三模型方向一致——中国无 DNR 专门立法，但实践中可通过同意书形式执行。Mini 的表述略偏乐观（"法律允许"），Gemini 最准确（"无专门立法，但实践中可执行"）。
- **置信度**: 高。
- **最终采纳**: 以 Gemini 的审慎表述为准——"中国目前无 DNR 专门立法，但实践中通过签署放弃抢救同意书执行，法律效力基于患者自主意愿和家属代为决定权"。

### 5. 中国可用的法律工具

- **GPT-4.1-Mini**: DNR 同意书、委托代理人，部分试点城市推行生前预嘱相关文件。
- **Gemini-2.5-Flash**: 遗嘱（仅限财产）、委托书/授权书、**意定监护**（《民法典》规定）、生前预嘱（无专门立法但有参考价值）。
- **GPT-4.1-Nano**: 委托书、医疗授权书。
- **一致性判定**: **高**。三模型均提到委托书/授权书。Gemini 独家补充了**意定监护**这一《民法典》中的重要工具，是最有法律操作价值的建议。
- **置信度**: 高。
- **最终采纳**: 综合三模型，重点突出意定监护（Gemini 独家贡献）+ 生前预嘱 + 医疗授权委托书三大工具。
