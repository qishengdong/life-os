## 一、 E5 · 顶级三甲医院老年科推荐名单

老年科（老年医学科）不是简单的“看老年人病的科室”，而是**“老年共病管理、多重用药调整、老年综合征评估”**的托底科室。当老人同时患有高血压、糖尿病、骨质疏松且有轻微失智时，挂老年科是避免多科室重复开药和药物冲突的唯一解。

## 三、 挂号与就医“避坑防骗”实操指南

1. **不要盲目追求“第一人”专家号**：
   - 像宣武贾建平、华山郁金泰等顶级专家，号源基本在 1 秒内秒杀，普通子女极难抢到。
   - **实操策略**：第一步挂他们团队的**“副主任医师”或“记忆门诊专病号”**。这些医生有充足的时间为老人做详细的量表评估（通常需要 30-40 分钟），并开具核磁共振（MRI）或 PET-CT 检查。等所有检查结果出来后，再通过特需门诊或加号方式找顶级专家看一眼、定治疗方案。这样效率最高。

2. **带老人看记忆门诊前的“家属准备清单”**：
   - **录像证据**：失智老人面对医生时，往往会表现得“非常正常、非常配合”（临床上的“面具效应”），导致医生无法观察到真实症状。家属务必在日常生活中，**偷偷录下老人的异常行为**（如反复问同一个问题、无理取闹、找不到回家的路、藏东西等），在诊室里放给医生看。
   - **用药鞋盒**：将老人目前正在吃的所有药物（包括降压药、感冒药、保健品）装在一个盒子里带给医生，避免药物冲突。
   - **病史时间线**：用一张纸写明：什么时候开始丢钥匙？什么时候开始不认识孙子？什么时候性格变暴躁？字数控制在 200 字内，递给医生。

3. **警惕“脑萎缩 = 痴呆”的体检骗局**：
   - 很多民营体检机构或不规范的诊所，看到老人核磁共振报告写着“轻度脑萎缩”，就恐吓家属是“老年痴呆”，推销几万块的“溶栓针”或“活血保健品”。
   - **医学事实**：**脑萎缩是老年人的正常生理衰老现象**。脑萎缩不等于痴呆！只有当脑萎缩伴有明显的认知功能下降（通过 MMSE/MoCA 量表测定）和日常生活能力受损时，才能诊断为失智症。千万不要为此买单。
