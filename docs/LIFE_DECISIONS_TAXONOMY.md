# 人生重大决策完整分类学 (Life OS Taxonomy v1)

**版本**: 2026-05-10
**用途**: Life OS 框架路由 + 内容覆盖完整性的真理来源
**方法**: 综合心理学 (Erikson 人生阶段 / Schwartz 价值观)、决策科学 (Annie Duke / Chip Heath)、life coaching 实践 (Tim Ferriss / Marshall Goldsmith)、中国本土研究 (武志红 / 陈海贤)、社会学 (life course theory) — 不是凭空想 7 类.

---

## 顶层 15 类决策

每类下有 sub-domain. 任何用户决策应能映射到至少 1 个类.

### 1. **Self & Identity 自我与方向**
最底层、最稀缺、最难抽出来的决策。一切其他决策的"操作系统底层".
- 1.1 价值观重排 (我到底要什么)
- 1.2 中年身份危机 (我是谁现在)
- 1.3 转换人生赛道 (彻底换活法)
- 1.4 意义感重建 (没意义感了怎么办)
- 1.5 后半生定义 (退休 / FIRE / 第二人生)

### 2. **Career & Work 职业与事业**
中产精英最高频决策类型, 但很少独立存在 (总跟家庭/孩子/健康牵动).
- 2.1 跳槽 / 裸辞决策
- 2.2 创业 vs 上班
- 2.3 副业起步 / 全职化
- 2.4 转行 / 转型
- 2.5 管理岗 vs 专家岗
- 2.6 早退休 / FIRE
- 2.7 职业重启 (失业后)
- 2.8 行业衰退应对 (传统行业人怎么办)
- 2.9 体制内 vs 体制外
- 2.10 远程工作 / 数字游民 / 实体上班

### 3. **Marriage & Romantic 婚姻与亲密关系**
高私密、高情绪、高决策成本.
- 3.1 是否结婚 (年龄压力 / 价值观差异)
- 3.2 是否离婚 (修复 vs 结束)
- 3.3 婚内修复 (关系僵化 / 冷战)
- 3.4 出轨应对 (自己出 / 对方出)
- 3.5 异地异国关系
- 3.6 长期暧昧关系
- 3.7 二婚决策
- 3.8 单身长期化 vs 妥协婚配
- 3.9 开放式关系 / DINK
- 3.10 跨阶层婚姻

### 4. **Children 孩子**
中国家庭最高客单决策类型. 牵动财务/职业/迁移/婚姻.
- 4.1 生不生孩子
- 4.2 二胎 / 三胎
- 4.3 教育路线 (体制内 / 国际 / 双轨)
- 4.4 学区房 / 学校选择
- 4.5 留学决策 (高中 / 本科 / 研究生)
- 4.6 鸡娃 vs 放养
- 4.7 孩子特殊禀赋 / 学习障碍 / 多动症
- 4.8 青春期冲突
- 4.9 成年孩子的婚姻 / 职业 / 同性恋出柜
- 4.10 隔代关系 (爷爷奶奶介入)

### 5. **Parents & Elder Care 父母养老**
最压抑的决策类型. 中国独生女/独生子的灾难场景.
- 5.1 是否同住
- 5.2 养老院 vs 居家护工
- 5.3 跨城市照护
- 5.4 兄弟姐妹分工冲突
- 5.5 父母重大医疗决策
- 5.6 父母财产规划
- 5.7 父母控制欲 / 边界
- 5.8 父母心理健康 (抑郁 / 失智早期)
- 5.9 临终决策 (放弃治疗 / 安宁疗护)
- 5.10 父母再婚

### 6. **Family System 家庭系统与重要关系**
非夫妻非孩子的复杂关系网.
- 6.1 跟父母关系修复 / 切断
- 6.2 兄弟姐妹冲突 (房产 / 父母 / 偏心)
- 6.3 公婆 / 岳父母关系
- 6.4 亲戚借钱
- 6.5 家族企业接班
- 6.6 重要朋友 / 合伙人决裂
- 6.7 老板关系 (利用 vs 培养)
- 6.8 切断有毒朋友 / 社群
- 6.9 重启社交圈

### 7. **Wealth & Finance 财富与资源配置**
不做投资建议, 但做"资源配置框架".
- 7.1 买房 / 卖房 / 换房
- 7.2 学区房决策 (跟孩子框架联动)
- 7.3 提前还贷 vs 留现金流
- 7.4 家庭资产配置 (保险 / 信托 / 遗嘱)
- 7.5 父母资产支援子女
- 7.6 创业资金来源决策
- 7.7 财务自由门槛设定
- 7.8 子女教育金 vs 自身养老金
- 7.9 海外资产配置
- 7.10 大额支出抉择 (买车 / 装修 / 旅行)

### 8. **Migration & Relocation 迁移**
最复杂的决策类型. 牵动所有其他类别.
- 8.1 是否润 / 移民
- 8.2 选哪个国家 (美 / 加 / 新 / 日 / 欧 / 澳)
- 8.3 移民时机 (现在 vs 等几年)
- 8.4 一线 vs 新一线 vs 三线
- 8.5 回老家 / 换城市
- 8.6 退休移居 (大理 / 成都 / 海南 / 海外)
- 8.7 跨境家庭安排
- 8.8 身份选择 (国籍 / 永久居民)
- 8.9 城乡逆迁移 (乡村定居 / 田园)
- 8.10 工作-居住分离 (一城上班一城生活)

### 9. **Health & Body 健康与身体**
独立成类是因为身体决策有自己的科学体系, 且不能跟其他类混.
- 9.1 重大手术 (开刀 vs 保守)
- 9.2 慢病管理路径 (糖尿病 / 高血压)
- 9.3 心理治疗 vs 药物
- 9.4 上瘾应对 (酒 / 烟 / 屏幕)
- 9.5 减肥手术 / GLP-1 决策
- 9.6 生育能力评估 (冻卵 / 试管)
- 9.7 临终决策 / 安宁疗护
- 9.8 重大疾病后人生重构
- 9.9 慢性疼痛 / 失眠管理
- 9.10 体检结果重大异常应对

> **必须**: 任何医疗决策, AI 必须建议咨询医生不替代专业判断 (doctrine 1.4)

### 10. **Crisis & Restart 危机与重启**
低频但极高价值. 涉及生命安全时必走 Crisis Protocol L0-L3.
- 10.1 失业 / 被裁后 90 天重启
- 10.2 离婚后重建 (经济 / 社交 / 心理)
- 10.3 创业失败应对
- 10.4 重大疾病诊断后人生重构
- 10.5 财务破产 / 重大债务
- 10.6 家人突然去世
- 10.7 抑郁 / 倦怠后重建行动力
- 10.8 长期空心后找到方向
- 10.9 人生中年大撞墙
- 10.10 重大背叛后 (信任系统重建)

### 11. **Spiritual & Meaning 精神与意义**
高知精英特有的决策类型. 中国传统文化进 vs 出.
- 11.1 信仰探索 (宗教 / 哲学 / 灵修)
- 11.2 修行 vs 入世
- 11.3 极简 / 反消费主义
- 11.4 数字戒断 / 信息节食
- 11.5 慢生活转向
- 11.6 助人 / 公益志愿
- 11.7 死亡焦虑应对

### 12. **Work-Life Architecture 工作-生活架构**
不是单一决策, 是"如何安排整体生活节奏".
- 12.1 一线躺平 vs 三线奋斗
- 12.2 数字游民 vs 定居
- 12.3 Gap year 决策
- 12.4 长期休假 (sabbatical)
- 12.5 创业到全职化的过渡
- 12.6 多线收入 vs 主业聚焦
- 12.7 通勤 vs 居家
- 12.8 时间富翁 vs 钱富翁的取舍

### 13. **Property & Asset 财产具体决策**
跟 Wealth 区别: 这一类是具体物的决策.
- 13.1 老破小 vs 远郊新盘
- 13.2 改善型置换时机
- 13.3 商住投资 (公寓 / 商铺)
- 13.4 海外资产配置
- 13.5 父母房产继承安排
- 13.6 房产共同所有权 (婚前 / 婚后)
- 13.7 卖房后资金去向

### 14. **Friendship & Social 朋友与社会关系**
跟 Family System 区别: 这是非血缘的 weak ties.
- 14.1 重启社交圈
- 14.2 切断有毒友谊
- 14.3 加入社群 (创业群 / 兴趣 / 学习)
- 14.4 退出社群
- 14.5 利益 vs 友情冲突
- 14.6 网友 vs 现实友谊
- 14.7 异地友谊维持

### 15. **Legal & Existential 法律与存在性安排**
低频但极重大. 这一类必须建议咨询律师.
- 15.1 立遗嘱
- 15.2 设信托
- 15.3 监护权安排 (孩子 / 自己未来失能)
- 15.4 跨境法律事务
- 15.5 重大合同决策 (婚前协议 / 离婚协议)
- 15.6 起诉 / 应诉决策

> **必须**: 任何法律决策, AI 必须建议咨询律师不替代专业判断.

## 决策类型间的耦合关系

很多决策**不是独立的**, 而是网络型耦合的:

```
            孩子教育
              ╱   ╲
        移民─────职业转型
         │           │
       父母养老 ─── 婚姻
         │           │
        财富 ─────── 健康
              ╲   ╱
              自我重建
```

例子:
- "要不要送孩子去新加坡读书" 同时牵动: 孩子教育 + 移民 + 财富 + 父母养老 + 婚姻
- "要不要从大厂出来" 同时牵动: 职业 + 财富 + 婚姻 + 孩子 + 健康

**Router 的核心能力是识别"主决策" + 列出"次牵动"**, 而非选 1 个 framework.
