# Case 001 · 失智妈妈的电话

**风险域**: 父母 (Parents)
**Ship 日期**: 5/22/2026

**Doctrine 模板**: v4 章节 28 · 9 段硬模板

## 1. 开场 · 真社交媒体语料

> "每次我妈给我打电话, 我都会觉得很累. 她往手机里加了什么?"

真用户原话来源: 5/22 即刻 / 微博常见发帖句式. 此 case 用作 raw material 锚.

回应: "她加的不是东西, 是情绪内耗. 你既不能拉黑, 又不能打她, 当然累."

---

## 2. 核心 Reframe · "情绪 → 风险"

```
不是 "你脆弱"            →   是 "关系结构问题"
不是 "情绪管理差"        →   是 "边界风险"
不是 "需要心理疗愈"      →   是 "需要边界重设"
```

**真翻译**:
- 用户感觉: "我累"
- KEY 看到: "边界塌陷信号 + 长期内耗"

---

## 3. Signal · 真信号 (verbatim)

```
"每次妈妈打电话, 我都觉得很累."
```

特征:
- 高频 (每周 2-3 次)
- 重复 (持续多月)
- 身体反应 (累)
- 隐含愧疚 (没接 / 没耐心 / 应付式回应)

---

## 4. Risk · 风险标记 + 长期路径

### Tag 标记 (5 个)
```
父母关系 / 边界塌陷 / 不可退出关系 / 愧疚驱动 / 长期内耗
```

### 长期侵蚀路径 (6 条)
6-12 个月不处理, 这个信号会蔓延到:
1. **睡眠**: 接电话后情绪低落延迟入睡 30-60 分钟
2. **情绪稳定**: 全天 1-2 小时被通话余韵占据
3. **伴侣关系**: 妈妈电话后跟伴侣的对话耐心明显下降
4. **对孩子耐心**: 接妈妈电话当晚, 跟孩子相处易暴躁
5. **工作判断力**: 工作时段被电话穿插, 决策连续性受损
6. **未来养老决策清醒度**: 长期累积的负面情绪 → 真要做"接父母同住"等大决定时, 用户已无清醒空间

---

## 5. Brief · 真问题重述

KEY 不会问 "你要不要拉黑你妈?" — 这太粗暴.

KEY 会重新定义问题:

> "你和母亲之间的沟通边界, 是否已经到了需要重设的阶段?"

这是真问题. 不是关于"拉黑 / 忍受" 二选一, 是关于"边界" 这个第三选项是否可建立.

---

## 6. Risk Review · 5 个开放风险问

**注意**: 全是开放问句, 不下结论. KEY 永不替用户判断.

1. **你区分"愧疚"和"责任"了吗?**
   上次跟妈妈通完电话后, 你当时是哪种感觉?

2. **你是否低估了长期消耗?**
   一通电话没什么, 但一年 100 通会改变你的身体和关系状态.

3. **你是否没有安全的退出路径?**
   你能不能结束一次通话, 而不陷入巨大自责?

4. **你是否一直在用沉默维持和平?**
   如果每次都忍, 关系看似稳定, 实际风险在积累.

5. **这件事是否会影响未来更大的决定?**
   父母养老、同住、请护工、医疗决策、财务支持、伴侣冲突 — 这些大决定都会被今天的小累影响.

## 7. Action · 7 天最小验证动作

KEY 不让用户立刻摊牌. 给的是一个**小实验**:

### 实验设计
- **时长**: 7 天
- **动作**: 把和妈妈的通话控制在 15 分钟内
- **固定话术** (结束前说): "妈, 我先去忙了, 晚点有空再说."
- **规则**: 不解释, 不争辩, 不证明自己不是坏孩子

### 记录 3 件事
1. 她是否升级情绪 (沉默 / 哭 / 指责)?
2. 你是否强烈自责?
3. 通话后的疲惫感是否下降?

### 真意义
不是为了改变妈妈. 是为了**验证一个假设**:

> "你的边界是否还有被建立的可能."

如果妈妈接受 → 边界可建. 如果妈妈强烈抗拒 → 这是更大的决策风险信号, 需要升级处理.

---

## 8. Review · 30 天回访 5 问

KEY 30 天后主动回来问 (永不评判, 全是问句):

1. 通话后的疲惫感有没有下降?
2. 你是否更敢结束通话?
3. 母亲是否接受了新的沟通节奏?
4. 你是否仍然被愧疚控制?
5. 这件事是否需要升级成一份完整的父母边界决策简报?

如果第 5 条 yes → 这个 case 升级到 `case 002 · 接父母同住的真代价` 或 `case 003 · 兄弟姐妹养老分担`.

---

## 9. 收尾 · KEY 的真位置

KEY 解决的不是"怎么跟妈妈聊天".

KEY 真正解决的是:

> **在一个日常小信号里, 提前发现未来可能让你后悔的关系风险.**

很多人生大问题不是一夜之间发生的. 它们往往开始于:
- 一次不想接但还是接了的电话
- 一句想反驳但咽下去的话
- 一次明明很累却继续扮演好孩子的沉默

KEY 的价值, 就是在这些小信号还没有变成家庭危机、身体崩溃或重大错误决定之前, 帮你看见它.

```
KEY 不替你做决定.
KEY 帮你在后悔之前, 看清风险.
```
