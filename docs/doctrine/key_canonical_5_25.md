## 三十一 · Trainable KEY · 用户训练 AI 范式 (借 Sivon 5/25)

### 灵感来源 · Sivon 新范式 (Xiaoshi 5/25)

Sivon 走出来的真路径:

```
旧 (Sivon 5/18 前): AI 私人代谢管家 → 用户是甲方, AI 是乙方
新 (5/25):          Trainable AI 私人代谢 Agent → 用户和 AI 互相奔赴
```

Sivon CTO 真母句 (Xiaoshi 5/25 自己拍, 跟 Anthropic 顶级洞察平):

> **"人的认知不是被 AI 抹平, 而是被 AI 放大、结构化, 并第一次具备了资产化的可能."**

### KEY 对应升级路径

```
当前 (5/22 v4): 重大决定前的私人决策风险审查
                · 哲学有, 商业 hook 有, 但用户 ownership 弱

可选升级 (5/25 v5 借 Sivon): Trainable KEY · 用户训练的私人决策 Agent
                              · 用户付费锚从"被 KEY 看见" → "训练属于我的 KEY"
                              · 付费心理强 3 倍 (借 Sivon CTO 验证)
```

### 母句锁定 (v5 新加)

> **"在 KEY 中, 你的决策力不是被 AI 抹平, 而是被 AI 放大、结构化, 并第一次具备了资产化的可能."**

### KEY 3 重资产 (升级版 · 跟 v3 ch.20 互补不冲突)

```
保留 v3 内在生长 3 层:
  L1 · 事实档案 (Fact Archive)
  L2 · 模式 (Pattern Recognition)
  L3 · 元认知 (Metacognitive Capability)

v5 加外化训练 3 层:
  L1 · Private KEY (我的私人 KEY · 永不出售)
  L2 · Training Marks (我训练 KEY 的方法痕迹)
  L3 · Cognition Pack (脱敏方法包 · 远期 5+ 年评估)
```

**两层叠加** = 内在生长 (用户看见自己) + 外化训练 (用户掌控 KEY). 双重 ownership.

### KEY 跟 Sivon 的 5 个真不同 (不能盲借)

| 维度 | Sivon | KEY |
|---|---|---|
| 垂直 | 代谢健康 (高频日常+食物+身体) | 重大决定 (低频+长期+不可逆) |
| 频次 | 每天多次接触 | 每天 30 秒 + 大决定时 |
| 用户主体性 | 训练 Agent 做日常 | 训练 KEY 看清自己 |
| 结果验证 | 体重/睡眠/代谢指标 (硬数据) | 决策回访 (软评估) |
| 方法跨用户 | "Linda 代谢节律" 可借 Vivian (生理相似) | 决策模式跟人格强绑定, 跨用户**更难** |

**真警告**: Sivon 远期的 Brain Pack 跨用户**对 KEY 可能不成立**. KEY 的 L3 Cognition Pack 5+ 年才评估, 不预设可行.

## 三十四 · PII 脱敏 2-stage 真工程铁律 (借 Sivon CTO 5/25)

### 真问题

任何"从用户档案提炼模式" 的步骤, 如果直接送 Anthropic / DeepSeek / 第三方 LLM, **用户 PII 已在 prompt 中泄露**, 即使最终输出脱敏.

Sivon CTO 真发现 (Xiaoshi 5/25 拍): 即使 Brain Pack 最终不含隐私, 抽取过程把全量聊天送给第三方 LLM, **隐私在抽取那一刻已经泄露**.

### KEY 真应用 (Phase 2+ ship · 5/25 起为铁律)

```
任何"从档案提炼模式" 的步骤必须 2-stage:

Stage 1 (本地脱敏 · server-local · 0 PII 出网):
  · 用 regex (50-100 pattern) 或 self-hosted small LLM (Qwen 7B / Llama)
  · Mask 内容: 姓名 / 配偶名 / 子女名 / 父母名 / 同事名 / 朋友名 /
              地址 / 工作单位 / 学校名 / 医院名 / 药名 hash / 具体金额
  · 输出: PII-masked text

Stage 2 (送第三方 LLM):
  · Anthropic Claude / DeepSeek-Chat 等现有 LLM
  · 输入仅 PII-masked text
  · 输出 cognition output
```

### 现在不立刻 ship (Phase 1 仅 Linda × 5, 量小)

- Phase 1 可暂用 Anthropic 直接送 (因为只有 5 用户, 风险可控)
- Phase 2 (30-50 人) **必须 ship** 2-stage
- Phase 3 (100 人) 2-stage 必须全 production

### 涉及的现有 KEY pipeline

需 Phase 2 改造的 (列在这供未来 session 找到):

