## 2. 我们收集什么

### 2.1 你主动提供的
- 生日 / 性别 (建档时填写)
- 决策描述 (你提交的每个决策的内容)
- Onboarding 访谈答案 (价值观 / 人格 / 人生事件)

### 2.2 系统自动生成的
- 用户唯一标识 (UUID, 浏览器 localStorage)
- AI 从你对话里抽取的 fact (RMC 卡)
- AI 写给自己的 brain 备忘录
- 决策 + AI 回答的完整记录
- AI 自己许下的 commitments

### 2.3 我们**不**收集
- 真实姓名 / 身份证号 / 银行卡号
- 通讯录 / 短信 / 通话记录
- 浏览器 cookie 跨站追踪
- 设备指纹 / IP 地理位置

---

## 3. 我们怎么用你的数据

### 3.1 主要用途
- 给你的决策提供个性化分析 (注入到 prompt)
- 跨决策保持连贯 (记得你之前说的)
- 周期性蒸馏成 brain.md (让 AI"懂你")

### 3.2 我们**不**做的
- 不卖给第三方
- 不做广告投放画像
- 不用你的数据训练我们的模型
- 不分析为商业 insights 出售

---

## 4. 数据存哪 / 谁能访问

### 4.1 数据存储
- 你的全部数据存在 Life OS 的 VPS (位于 [中国大陆/海外]) 上的 SQLite 数据库
- **明文存储** (V0 诚实告知). V2 升级到加密存储.
- 备份每日打包到独立存储, 保留 30 天

### 4.2 谁能访问
- **只有 Life OS 的工程师** (你 + 创始人) 在 debug / 用户支持时可访问
- 我们不会未经你同意查看你的具体内容
- 任何主动查看必须留 audit log

### 4.3 第三方
- **DeepSeek API**: 我们调用 DeepSeek 给你做分析时, 会发送你**当前对话内容**给 DeepSeek, **但不带 user_uid**. DeepSeek 的隐私政策: https://platform.deepseek.com/privacy
- **不与其他第三方共享**
