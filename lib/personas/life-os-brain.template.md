# Life OS Brain — Per-User Memory (Template)

> 这是 brain.md 的**模板**。每个用户有自己的副本, 存在 SQLite `user_brain` 表里。
> 内容由 fact-extractor + 周期性 consolidation 自动维护, 用户可在 /history 页编辑。

## 关于这位用户

(Identity / Values / 长期愿景 — 由 Onboarding 深度访谈填充, V1 上)

## 当前状态 (rolling, 30 天内)

(职业 / 财务 / 关系 / 健康 — 自动从 RMC factual + episodic 蒸馏)

## 已识别的人生模式 (pattern memory)

(由 Pattern Detection Agent 在 V1.5+ 填充, 例:
- "用户第 N 次因为'怕父母失望'放弃自己的选择"
- "用户每次重大决定前都要先寻找权威认可")

## 关键关系网络

(配偶 / 父母 / 孩子 / 老板 / 重要朋友 — 关系动态)

## 历史重大决策

(已经做过的决定 + 当时的考虑 + 后来的实际结果, 用于跨时间一致性参考)

## 未解决的人生议题 (open loops)

(用户提了但还没想透的事, 未来主动 callback 时用)

---

**注意**: 这个文件由 Life OS 自动维护, 用户对话时不会主动 callback 里面的具体细节,
除非用户当前问题直接涉及。这是 doctrine: "默认不主动 callback, 自然引用即可"。
