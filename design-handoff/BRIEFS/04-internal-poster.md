# Brief 04 · Internal Demo Poster (KEY Brand Launch)

**Priority**: P0
**Week**: 1
**Estimated time**: 4-6 hours
**Iterations expected**: 2-3 rounds before final

---

## 用途

创始人需要一份海报, 给他**资深媒体老同行**展示 KEY 项目的概念. 这是 KEY 品牌**第一份对外的视觉物料**.

受众是中国顶级 lifestyle 杂志的前同事 / 同业 / 前辈. 他们对 typography / 留白 / 印刷质感 有职业级判断力. **任何 SaaS 套路 / 通用 AI 海报美学 / Instagram 滤镜感都会立刻折损可信度**.

这份海报必须做到:
- 30 秒内让受众感知到三件事:
  1. 这是一个 AI 产品, 但完全不像 AI 产品
  2. 这件事有真正的概念锚点 (不是概念包装)
  3. 创始人懂出版物 craft, 不是又一个程序员 pitch

---

## 整体气质

参考 SECTION B (Master Directive). 这份海报应该是: **像一本你愿意从书店带回家、放在床头不舍得丢的严肃刊物的创刊号封面**.

## 海报版面文案 — 中文主版 (锁定)

### 顶部 — Brand Mark

```
KEY
```

(用 Brief 01 的 wordmark V1-A, 如果 wordmark 还没定稿, 用大写 serif 字体占位)

正下方一行小字, 极小字号, 中性灰:

```
项目内部 demo · v1 · 2026
```

### 上中区 — Tagline

```
Find the key before you decide.
决定之前, 先找到关键.
```

中英双行. 英文 28pt Lora Italic 在上, 中文 24pt 思源宋体 Regular 在下. 中间一条 0.5pt Deep Burgundy 细线分隔, 线长 80mm 居中.

### 视觉主体区 — 大幅图像

**只放一张图. 不要多图拼贴.**

三个图像方向供你选 (任选 1, 不混用), 跟 Day 19 的 brief 一样:

#### 方向 A · 静物 (创始人最倾向, 我也推荐)

一张深色木桌局部. 桌上有: 一支万宝龙或类似品牌的钢笔 (横放, 笔尖朝左), 一沓被折角的稿纸 (空白, 不写字), 一盏半暗的台灯只照亮局部, 角落有一杯只喝了三分之一的茶 (热气将散未散). 整张图**黑白**, 高反差暗调, 颗粒感强 (像 Tri-X 推感光的胶片).

这是"刚刚有人写完一份重要的东西, 暂时离开了书桌"的瞬间.

#### 方向 B · 人物背影

一位 45-55 岁亚洲面孔的男性或女性, 只拍后脑勺 + 半边肩颈, 面朝一扇大窗, 窗外是傍晚城市的天际线 (虚化, 不可辨识具体城市). **不要拍到正脸. 不要表情**. 一份 A4 纸在他/她的手里 (虚化, 看不清内容). 黑白.

这是"刚刚读完一份很重的东西"的瞬间.

#### 方向 C · 一个物 (极简)

单独一张折叠了三折的私人信件特写, 表面有压痕 / 茶渍 / 一处删改, 压在一本厚的精装书上. 周围全是黑色或深棕暗调. 极简, 物件占画面 30%, 其余全是负空间.

这是"一封被反复读过的私人简报"的隐喻.

**所有方向的共同要求**:
- 黑白 + 颗粒
- 中性暗调, 不要明快
- 不要露脸
- 不要现代科技元素 (手机 / 电脑 / 屏幕)
- 不要 logo / 文字出现在图内
- 图像高度占整张海报 35-40%

### 中下区 — Manifesto Hero Text

这是海报的"灵魂区". 三段, 每段独立成一个 visual unit, 段与段之间 60mm 间距.

```
有些决定, 不能冲动, 不能外包, 也不能只靠安慰.

父母养老. 孩子出路. 婚姻去留. 职业转身. 要不要迁移.

我们把这些决定, 整理成一份
像被写出来的 — 不是被生成出来的
私人决策简报.
```

**排版要求**:
- 思源宋体 Regular, 字号 36pt (中文), 行高 1.5
- 每段左对齐, 不缩进
- **第二段五个词组 "父母养老. 孩子出路. 婚姻去留. 职业转身. 要不要迁移."** — 每个之间用**句号断开**, 制造极强的节奏感. 这是 craft 核心, **不要**改成顿号 / 逗号 / 中点.
- 第三段的 "像被写出来的 — 不是被生成出来的" 必须独占一行, 中间用 em dash (—) 不是 hyphen (-)
- 整段不要任何加粗 / 斜体 / 颜色变化. 全部纯黑 / 深棕

### 下中区 — 方法论 (小节式, K-E-Y backronym)

一个紧凑的版式块, 类似杂志目录页. 字号小, 但布局精致.

标题:
```
方法 · METHOD
```
12pt 思源黑体, 字距 +200, 全大写 (英文部分)

正下方一道 0.5pt Deep Burgundy 水平线, 全宽.

正文 (这是 K-E-Y backronym, 必须呈现):
```
K   Know the context.       记得你的真实背景, 不每次重新问.
E   Expose the trade-offs.  揭示每条路的代价, 不替你选.
Y   You decide.             最终判断仍属于你.
```

**排版**:
- 字母 K/E/Y: 24pt Lora Italic, Deep Burgundy (#6E1F2A)
- 英文短句: 14pt Lora Regular, Ink Black
- 中文解释: 13pt 思源宋体 Regular, Warm Gray
- 三列对齐: K-E-Y 字母 / 英文句 / 中文解释. 中间用 tab 间距 (10mm 和 12mm)

### 底部 — 签名 + 注脚

最底部一道 0.5pt Deep Burgundy 水平线, 上方 15mm 一段小字, 三行:

```
KEY Editorial Office  ·  Founder Edition  ·  Issue No. 001

A service disguised as a publication. Decision counsel for the moments that matter.

仅供内部讨论. KEY 由 LifeOS 架构驱动. 创始会员限 100 名. AIGC 备案中.
```

**排版**:
- 第一行: 10pt 思源黑体 Regular, 字距 +100, 全大写英文
- 第二行: 11pt Lora Italic, 居中, 行高 1.6
- 第三行: 9pt 思源黑体 Regular, Warm Gray

底部右下角加一个**编号印章** (SVG 简单画一个圆形 stamp), 内容:

```
KB · 001
```

字号 8pt, 圆形直径 18mm, Deep Burgundy, 模拟印章压痕效果 (略不规则边缘, 有"漏墨"质感).

## 设计规格汇总

### 尺寸 + 比例
- A2 vertical: 420 × 594 mm, 印刷出血 3mm
- 数字版: 1417 × 2008 px @ 96 DPI (印刷 @ 300 DPI: 4961 × 7016 px)
- 安全边距: 25mm 四周
- 双语展示: 中英两张并列, 总尺寸 840 × 594 mm

### 色彩 (锁定)
```
背景         #F7F3EA   Paper White
主文字       #111111   Ink Black
副文字       #5A554F   Ink 500 (派生)
强调 / 印章   #6E1F2A   Deep Burgundy
注脚         #BDB6AA   Warm Gray
```
**禁用**: 任何鲜艳色 / 渐变 / 透明叠加

### 字体 (用 Brief 03 最终方案)
- 海报 V1 阶段 Brief 03 可能还没定, 用占位组合: Lora + 思源宋体 + Inter + 思源黑体
- 如果 Brief 03 在你做海报时已经定稿, 用定稿字体

### 装饰元素 (酌情用)
- Drop cap (首字下沉): 可在 manifesto 第一段开头用 (深棕色大字, 占 2 行高)
- Asterism (※): 段间可用一个居中的小三角点缀, Deep Burgundy
- Roman numerals: I, II, III, IV, V
- 印章式编号: 右下角圆形 stamp

## 给 Claude Design 的 3 条原则

```
1. 当你想加点什么的时候 — 不要加. 减.

2. 让一句话做所有的工作.
   manifesto 段那五个词组的句号节奏 = 海报的灵魂.
   K-E-Y backronym = 产品哲学的压缩.
   其他一切只是衬托.

3. 这张海报代表的产品哲学就是 "authored, not generated".
   海报本身必须像被人精心写出来的, 而不是设计软件套出来的.
```
