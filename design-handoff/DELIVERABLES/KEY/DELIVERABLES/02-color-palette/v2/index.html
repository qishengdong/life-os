Palette V2

Status colors added (3). Print Pantone reference codified. Dark-mode policy declared. Reserved scale steps (paper-500, burgundy-300) earn explicit roles. Long-form reading preference set to Ink 700.

I  ·  What changed since V1Five additions

  1. Status colors — three: success (sage), warning (amber), danger (ember). Inherited from existing code use; codified into the palette with explicit usage rules.
  2. Print Pantone reference — five core colors, each with a Pantone equivalent, recommended stock, and a printer note. Indicative — wet proof required before commitment.
  3. Dark-mode policy — explicit: KEY does not support OS-level dark mode. Night Navy is a reserved surface, never an inverted theme.
  4. Reserved scale steps documented — paper-500 and burgundy-300 each get an explicit role rather than sitting in the JSON unexplained.
  5. Long-form body color — Ink 700 (#2A2622) is the new default for sustained-reading surfaces. Ink 500 is short secondary type only.

Usage rules — applies to all three

✓   Allowed

  • Inline text in body — 10–15 chars at most
  • Small icon fills (≤ 16 px)
  • Badge / pill backgrounds (≤ pill size)
  • Focus ring on form fields
  • The tint variant as an emphasis-block background (small region only)

✗   Forbidden

  • Page background
  • Card / section background (anything larger than a badge)
  • Button face — KEY has no SaaS buttons
  • Headlines or body type — accent only
  • Combining two status tints in the same visual region

Burgundy remains the primary accent. Status colors are only invoked when the underlying state genuinely requires red / orange / green semantics — not as decoration.

III  ·  Burgundy tint#F5E8E9 — kept, with rules

The single field-grade color in the system. Reserved for small emphasis regions only.

✓   Allowed

  • Follow-up reminder block (30 / 90 / 365 day prompt)
  • Brief callout — Inspector C16 surface, matched_text highlight
  • Email validation soft hint (paired with burgundy text)
  • End-of-section “decision point” emphasis

✗   Forbidden

  • Page or section background
  • Card default background — that’s Paper 100
  • Button hover state — collides with focus / pressed states
  • Used together with status warning tint in the same view

IV  ·  Dark mode policyThe Night Navy line

Policy · locked

KEY does not support OS-level dark mode. Night Navy is a reserved surface, never an inverted theme.

Why. KEY’s constitution is “a serious publication, not an app.” A magazine doesn’t invert at sundown. The Paper background is the document — it stays Paper. Night Navy is reserved for surfaces the brief explicitly names: KEY Brief PDF cover, KEY Letter cover, admin, investor-deck dark pages.

@media (prefers-color-scheme: dark) { … } MUST NOT swap Paper to a dark theme on the public web.

V  ·  Reserved scale stepsPaper 500 + Burgundy 300

Two values flagged in V1 as “reserved with no current use.” V2 commits each to one specific role.

Paper 500
#D6CFC2   ·   deep sunken
Deep-sunken surface — used inside Paper 100 cards, never as page background. Example: a fold-down aside on a Brief page (further sunken than Paper 300), or the inset region of a membership tier card. Reserved use; expect 1–2 instances per page maximum.
Burgundy 300
#B05863   ·   muted accent
Muted-state burgundy. Used for revoked-invite strike-through, disabled tier indicator, “closed” status (e.g. founder cohort full). Reads as “burgundy but past tense.” Not a substitute for status danger — different semantic.

VI  ·  Long-form preferenceInk 700, not Ink 500

For sustained-reading surfaces — KEY Brief body, KEY Letter, /methodology long-form — body type should be Ink 700, not Ink 500. The half-step is small in isolation and significant over many paragraphs.

Ink 700 #2A2622 · 12.8:1

You came in asking whether to leave the job. The job is the symptom. The decision underneath — and the only one you can act on this quarter — is whether to lower the cost of being wrong about your last move. That is the work.

Ink 500 #5A554F · 6.9:1

You came in asking whether to leave the job. The job is the symptom. The decision underneath — and the only one you can act on this quarter — is whether to lower the cost of being wrong about your last move. That is the work.

Ink 500 keeps its role: short secondary type — footnotes, captions, mast-meta. Anywhere the reader stays for more than a paragraph, Ink 700.

VII  ·  Print referencePantone & CMYK

Indicative press values. A printer must pull a wet proof before committing — these are starting points, not contract.

ColorHEXCMYKPantoneNote
Deep Burgundy #6E1F2A 32 / 89 / 72 / 42 1815 C Four-color build leans purple on coated stock. PMS 1815 C gives a slightly redder, more consistent result — recommended for Founder Edition.
Ink Black #111111 0 / 0 / 0 / 93 Black 6 C Slightly off pure K to retain ink-on-paper feel. For richer black on cover stock, request rich-black build 60-40-40-100.
Paper White #F7F3EA 2 / 4 / 9 / 0 7527 C Stock recommendation: warm-white uncoated text stock, 100–120 gsm (e.g. Mohawk Superfine eggshell, GF Smith Colorplan natural white).
Night Navy #141923 78 / 67 / 53 / 80 Black 6 C + 5% PMS 281 C Pure CMYK build tends muddy. Two-pass (black + 5% deep blue) keeps Night Navy's cool cast on press.
