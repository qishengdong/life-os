How to read this

The handoff rhythm

Each deliverable is a self-contained page. Each ends with a list of questions I expect back. Review at whichever pace suits — the four are independent of each other except where flagged inside.

For the Founder

  1. Skim each deliverable in TOC order — 5 minutes each.
  2. Note anything that feels wrong against your magazine instincts.
  3. Forward this URL (or the folder) to Claude · technical lead.
  4. Relay feedback back to me, in the form Claude writes it.

For Claude · technical lead

  1. Read each README.md before the visual file — context first.
  2. Use the “V1 → V2 feedback I expect” section at the bottom of each as the question template.
  3. JSON / CSS / Markdown files are engineering-ready; SVG outlines arrive in V2.
  4. Iterations expected: 2–3 per brief. P0 deliverables should converge inside three weeks.
